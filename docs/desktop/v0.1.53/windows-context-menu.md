# 📌 Modul - FileType
# Version: 0.1.53
# Aciklama: Registry tabanli Explorer context menu ve uygulama ici popup menu notlari

Bagimli Oldugu Katman: Service | Tool | View | Language | Config

v0.1.53, dosya iliskilendirme akisina Windows Explorer sag tik menusu yazar.

Eklenen Explorer komutlari:

- UniZip ile ac
- Buraya cikar
- Klasore cikar
- Arsivi sina
- UniZip arsive ekle

Ayarlar > Sistem icindeki sag tik menu secenegi kapaliysa Registry context menu yazilmaz.
Sag tik menulerini gruplandir secenegi aciksa UniZip alt menu olarak yazilir.

Uygulama ici listeye de sag tik menu eklendi:

- Ac
- Secili cikar
- Ekle
- Yeniden adlandir
- Sil
- Yolu kopyala
