# 📌 Amac: Sistem sekmesindeki dosya iliskilendirme ekranini 7-Zip gorunumune daha yaklastirmak
# 📌 Modul - FileType
# Version: 0.1.44
# Aciklama: Uzanti alani sistem sekmesinden ayrildi, tablo genisletildi, + butonlari kolonlarla hizalandi

Bagimli Oldugu Katman: View | Language | Config

## Degisiklikler

- Sistem sekmesindeki dar form yapisi kaldirildi.
- Arsiv uzantilari metin alani UniZip sekmesine tasindi.
- Sistem sekmesi 7-Zip gibi sadece iliskilendirme tablosuna ayrildi.
- + butonlari kullanici ve tum kullanicilar kolonlariyla hizalandi.
- Uzanti kolonunda basindaki nokta kaldirildi.
- Uzanti satirlarina sistem dosya ikonu renderer eklendi.
- Tablo satir yuksekligi ve grid gorunumu 7-Zip stiline yaklastirildi.

## Not

Community surum Windows Registry'ye dogrudan yazmaz. Butonlar simdilik Windows varsayilan uygulama ayarlarini acar. Gercek tum kullanicilar iliskilendirmesi installer/admin katmaninda ele alinmalidir.
